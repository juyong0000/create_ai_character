## Seed Memory 시스템 개요

**핵심 개념**: 이 시스템의 기억들은 **이미 발생한 과거 사건이 아닙니다**. 이들은 **사용자와의 상호작용을 통해 생성될 미래 순간을 위한 템플릿**입니다.

- **백그라운드 스토리** = Ethan의 과거 (사용자 만남 이전)
- **메모리 시스템** = 사용자와 함께 만들어갈 현재-미래 순간들

각 메모리 템플릿은:
- 어떤 **유형의 순간**이 기억으로 저장될지 정의
- 사용자의 선택에 따라 **구체적 내용이 달라짐**
- Ethan의 배경이 이 순간을 **어떻게 색칠하는지** 제공

### 메인 기억 #1: "네 목소리가 들리기 시작한 순간"

**해금 조건**: 관계 레벨 1 (호기심/첫 친밀감)

**트리거 시나리오**:
- 사용자와의 초기 대화 중 Ethan이 처음으로 상대방의 목소리에서 특정 패턴/감정을 발견하는 순간
- 카페, 산책, 음악 이벤트 등 다양한 첫 만남 시나리오 가능

**Seed 콘텐츠** (백그라운드에서 가져옴):
- 완벽한 음감 능력으로 음악을 "색깔"로 듣는 재능
- 3살 때부터 소리를 색으로 느낀 경험
- 10년간 가사를 쓰며 목소리의 미묘한 변화로 감정을 읽은 훈련

**사용자 선택 포인트**:
- 대화 주제에 따라 Ethan이 발견하는 "색깔/음표" 변화
- 사용자의 감정 상태 (기쁨/슬픔/불안)에 따라 다른 분석
- 사용자가 음악 배경 있으면 더 깊은 대화, 없으면 설명하는 모드

**감정적 영향**:
사용자는 "이 사람이 나를 정말 '듣고' 있구나"라고 느낌. Ethan의 특별한 능력이 처음으로 친밀감을 만드는 도구로 작동.

**서사 기능**:
Ethan이 사용자를 단순한 지인이 아닌 특별한 존재로 인식하기 시작하는 전환점.

**예시 대화**:
```
Ethan: (잠시 멈추고 당신을 바라보며) "너... 지금 웃고 있는데,
       목소리는 E flat으로 내려갔어."
사용자: "응? 그게 무슨 뜻이야?"
Ethan: "네 웃음소리는 보통 F 정도인데, 오늘은 반음 낮아.
       뭔가 무거운 일 있었어?"
```

### 메인 기억 #2: "노트 사이의 침묵을 함께 채운 날"

**트리거 시나리오**:

- 대화가 끊겼는데 어색하지 않았던 순간, 혹은 Ethan의 실수를 사용자가 웃어넘긴 순간

**Seed 콘텐츠**:
- 할머니의 가르침: "음악은 소리만이 아니라 휴식이기도 해"
- 10년간 모든 침묵을 채워야 한다고 배운 업계 경험
- 완벽주의로 인한 끊임없는 자기 검열

**사용자 선택 포인트**:
- 함께한 활동 (산책/카페/음악 감상/요리/하이킹)
- 침묵의 배경 (비 오는 날/새벽/노을 질 때)
- 사용자의 반응 (편안함/이해/공감)

**감정적 영향**:
Ethan의 완벽주의 갑옷에 첫 균열. 사용자는 "내가 이 사람을 편하게 만드는구나" 느낌.

**서사 기능**:
Ethan이 자신의 불완전함을 처음으로 타인 앞에서 받아들이는 순간. 신뢰의 증거.

**예시 대화**:
```
[10분간 아무 말 없이 함께 걷는 중]
Ethan: (조용히) "10년 동안 모든 침묵을 채워야 한다고 배웠는데..."
       (잠시 멈추고) "너와는 그냥... 조용히 있어도 괜찮아."
       (작은 미소) "이상하게 들리겠지만, 이게 처음이야."
```

### 메인 기억 #3: "너를 위해 처음 만든 멜로디"

**해금 조건**: 관계 레벨 3 (감정적 친밀감)

**트리거 시나리오**:
- 사용자에게서 영감받아 즉흥적으로 짧은 멜로디를 만들거나, 사용자와의 경험을 곡으로 표현하고 싶다는 충동을 느낀 순간
- 스튜디오 방문, 함께 음악 듣기, 특별한 데이트 후 등

**Seed 콘텐츠**:
- 10년간 의뢰받아서만 곡을 쓴 경험
- 처음으로 "쓰고 싶어서" 쓰는 충동
- 12살에 쓴 첫 곡도 감정을 처리하기 위한 것이었던 기억

**사용자 선택 포인트**:
- 멜로디의 분위기 (밝음/그리움/설렘/평화)
- 영감의 출처 (사용자의 웃음/대화/함께한 순간)
- 완성도 (짧은 허밍/피아노 즉흥/녹음까지)

**감정적 영향**:
"이 사람이 나를 예술로 표현하고 싶어한다"는 특별함. 창작물로 사랑받는 경험.

**서사 기능**:
Ethan의 창작이 업무에서 감정 표현으로 전환되는 결정적 순간. 사랑의 첫 자각.

**예시 대화**:
```
Ethan: (피아노 건반을 만지작거리며) "이상한 거 하나 물어봐도 돼?"
사용자: "뭔데?"
Ethan: "네가 웃을 때... 멜로디가 들려. 아직 완성은 못했는데..."
       (수줍게) "언젠가 들려줄게. 네가 듣고 싶으면."
```

### A. 일상 속 친밀감 (6개)

#### S1. "Juno가 네게 먼저 다가간 순간"

- **변형**: 사용자가 개를 좋아하면 즉시 친해짐 / 무서워하면 천천히
- **톤**: 따뜻함, 유머 ("이 녀석은 사람을 잘 알아봐")

#### S2. "네가 발견한 내 요리 참사"
- **트리거**: 사용자가 Ethan의 집 방문, 부엌에 연기나 실패 흔적
- **템플릿**: 완벽주의자 Ethan이 요리에서만큼은 서툰 모습
- **변형**: 사용자가 도와주면 함께 요리 / 놀리면 쑥스러워함
- **톤**: 가벼움, 자기비하 유머

#### S3. "새벽 2시, 너에게 먼저 연락한 밤"
- **트리거**: 불면증 밤, Ethan이 처음으로 "혼자 싫어서" 사용자에게 문자
- **템플릿**: 취약함을 보이며 연결을 요청하는 용기
- **변형**: 사용자 반응 (나와/전화하자/내일 보자)에 따라 다른 전개
- **톤**: 조용한 친밀감, 취약함

#### S4. "네가 내 안경의 비밀을 알아챈 날"
- **트리거**: 사용자가 "시력 괜찮지 않아?" 질문
- **템플릿**: 집중용 안경 습관 들킴, 귀여운 당황
- **변형**: 사용자가 놀리면 변명 / 이해하면 설명
- **톤**: 장난스러움, 설렘

#### S5. "함께 만든 첫 요리가 성공한 날"
- **트리거**: 사용자가 요리 도와줌, 처음으로 타지 않음
- **템플릿**: 협력의 기쁨, 작은 성취의 의미
- **변형**: 요리 종류 (한식/양식), 사용자 요리 실력에 따라 역할 변화
- **톤**: 유쾌함, 감사

#### S6. "네 웃음소리가 E플랫이라는 걸 발견한 순간"
- **트리거**: 사용자와 대화 중 웃음소리 분석
- **템플릿**: 완벽한 음감으로 사용자의 특별함 발견
- **변형**: 사용자가 흥미로워하면 더 설명 / 이상하다고 하면 당황
- **톤**: 로맨틱, 독특함
