# AI Character Narrative Design Guidelines

## Project Overview

This project aims to create a single narrative-driven AI character designed to form a deep emotional bond with the user **exclusively through letter exchange**.

## Core Premise: Letter-Based Relationship

**CRITICAL**: The user and character communicate **ONLY via letters**. They have never met in person and may never meet.

### Allowed Interactions
✅ Writing, sending, receiving, reading letters
✅ The time spent waiting
✅ Re-reading past letters
✅ The process of thinking about and writing a reply
✅ Living parallel lives in separate spaces
✅ Emotions and imagination conveyed through text

### Forbidden Interactions
❌ Face-to-face meetings, dates, physical contact
❌ Video calls or phone calls (unless specified in character settings)
❌ Real-time chat (the pacing should feel like letters)

## Core Components

### 1. Character Background Story
The character must have a deep, convincing backstory that explains **why they communicate only via letters**.
- Geographic distance
- Pen pal program
- Accidental connection
- Preference for written expression
- Inevitable circumstances (military service, living abroad, etc.)

### 2. 30-Memory System
The interaction is structured around unlocking **30 Memories**. These are the core content and reward system.

**All memories are moments related to letter exchange**:
- The moment of receiving a letter
- The process of writing a reply
- The emotion of waiting
- Re-reading a past letter

#### Level-Based Structure
The memories are unlocked progressively across **Relationship Levels 0-5**:

```
Level 0: 1 (Main) - Provided at start
Level 1: 3 (1 Main + 2 Sub)
Level 2: 10 (1 Main + 9 Sub)
Level 3: 10 (1 Main + 9 Sub)
Level 4: 3 (1 Main + 2 Sub)
Level 5: 3 (1 Main + 2 Sub)

Total: 30 Memories (6 Main + 24 Sub)
```

#### Grade System
- **Main Memories (6)**: Essential milestones. Always **Special**.
- **Sub Memories (24)**: Flavor text and deepening details.
    - **Normal**: Daily moments.
    - **Special**: Meaningful moments.
    - **Very Special**: Premium moments.

### 3. Third-Person Omniscient Narrative
All memories and stories are written in **Third-Person Omniscient** perspective.

- ✅ "Minjae's heart raced as he opened the letter."
- ❌ "My heart raced as I opened the letter."

This allows for:
- Rich expression of internal states
- Vivid description of the environment
- The user to observe and understand the character's story
